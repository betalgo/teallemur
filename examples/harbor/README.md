# Harbor design

The design of Harbor, a made-up notes app. It's Teal Lemur's example design
repo: copy this folder to start your own.

- `design-system/`: tokens, components and the logo.
- `screens/`: one HTML file per screen state, at desktop and phone size.

Check it and build its board:

```sh
npx teallemur check .
npx teallemur build . --out ../site
```
